# DermoScan AI — веб-прототип

Интерактивный прототип мобильного приложения для скрининга и мониторинга кожных образований. Школьный исследовательский проект.

**Это не диагноз и не медицинское изделие.** Если образование растёт, меняется, кровоточит или не заживает 4 недели, покажите его дерматологу.

## Что умеет прототип

- Анамнез с факторами риска и «красными флагами», которые всегда ведут к рекомендации врача.
- Оценка снимка по признакам A, B, C, D (упрощённый алгоритм, без обученной нейросети).
- Проверка качества снимка: свет и резкость.
- Цифровой паспорт кожи: сравнение снимков одного образования во времени (размер в кадре, совпадение контура, цвет ΔE).
- Сводка для врача и печать.
- Русский и казахский языки.
